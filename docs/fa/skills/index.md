# مهارت‌ها

[نسخه‌ی انگلیسی ←](../../en/skills/index.md)

این دایرکتوری شامل مهارت‌های ایجنت هوش مصنوعی بسته‌شده‌ای است که با این دوره قاموس‌آن می‌شود. مهارت‌ها الگوهای پرامپت خودمختار هستند که می‌توانند توسط ایجنت‌های کدنویسی هوش مصنوعی (Claude Code، Codex، Cursor، Windsurf، و غیره) برای انجام کارهای تخصصی بارگذاری شوند.

## harness-creator

یک مهارت مهندسی هارنس درجه تولید برای ایجنت‌های کدنویسی هوش مصنوعی. شما را کمک می‌کند تا پنج زیرسیستم هارنس اصلی را ایجاد، ارزیابی، و بهبود دهید: دستورالعملات، وضعیت، راستی‌آزمایی، دامنه‌ی کار، و چرخه‌ی حیات جلسه.

### کاری که انجام می‌دهد

- **ایجاد هارنس از ابتدا** — AGENTS.md، فهرست‌های قابلیت، جریان‌های کاری راستی‌آزمایی
- **بهبود هارنس‌های موجود** — ارزیابی پنج‌زیرسیستم با بهبود‌های اولویت‌دار
- **طراحی تداوم جلسه** — تداوم حافظه، ردیابی پیشرفت، رویه‌های تحویل
- **اعمال الگوهای تولید** — حافظه، مهندسی پرامپت، ایمنی ابزار، هماهنگی‌ی چند ایجنت

### شروع سریع

فایل‌های مهارت در ریپازیتوری در [`skills/harness-creator/`](https://github.com/walkinglabs/learn-harness-engineering/tree/main/skills/harness-creator) زندگی می‌کنند.

```bash
npx skills add walkinglabs/learn-harness-engineering --skill harness-creator
```

برای استفاده‌ی آن با Claude Code، دایرکتوری `harness-creator/` را در مسیر مهارت پروژه‌ی خود کپی کنید، یا ایجنت خود را در فایل SKILL.md اشاره کنید.

### الگوهای مرجع

مهارت شامل 7 سند مرجع متمرکز است:

| الگو | زمانی استفاده کنید |
|---------|-------------|
| تداوم حافظه | ایجنت بین جلسات فراموشی می‌کند |
| زمان‌اجرای مهارت | بسته‌بندی جریان‌های کاری قابل‌استفاده‌ی مجدد به‌عنوان مهارت‌ها |
| مهندسی پرامپت | مدیریت بودجه‌ی پرامپت، بارگذاری JIT |
| ثبت ابزار | ایمنی ابزار، کنترل هم‌زمانی |
| هماهنگی چند ایجنت | موازی‌سازی، جریان‌های کاری تخصص |
| چرخه‌ی حیات و راه‌اندازی | قلاب‌ها، کارهای پس‌زمینه، آغاز |
| نکات مهم | 15 حالت شکست غیرواضح با اصلاح‌ها |

### الگوها

مهارت شامل الگوهای آماده‌ی استفاده است:

- `agents.md` — داربست AGENTS.md با قوانین کار
- `feature-list.json` — طرح JSON + فهرست قابلیت نمونه
- `init.sh` — اسکریپت آغاز استاندارد
- `progress.md` — الگوی گزارش پیشرفت جلسه
- `session-handoff.md` — الگوی تحویل جلسه

### اسکریپت‌ها

مهارت شامل اسکریپت‌های Node.js سادگی برای داربست، تصدیق، گزارش‌های ارزیابی HTML، و گزارش‌های معیار ساختاری است.

### نحوه‌ی ساخت این مهارت

`harness-creator` با استفاده از روش‌شناسی **skill-creator** توسعه یافت — روش‌شناسی ابزار فوق‌انسانی رسمی Anthropic برای ایجاد، آزمایش، و تکرار بر روی مهارت‌های ایجنت. skill-creator یک جریان کاری ساختاری (پیش‌نویس → آزمایش → ارزیابی → تکرار) با ابزارهای اجرای eval توسعه‌یافته، درجه‌دهنده‌ها، و بیننده‌ی معیار فراهم می‌کند.
