# خوش‌آمدید به پروژه‌ها

این بخش عملی Learn Harness Engineering است. خواندن سخنرانی‌ها کافی نیست — شما باید خود محیط‌ها را بسازید و ببینید که Codex، Claude Code یا سایر ایجنت‌ها تحت قوانین مختلف چگونه عمل می‌کنند.

## مرور پروژه‌ها

این دوره شامل ۷ پروژه‌ی پیش‌رفته و عملی است که به شما آموزش می‌دهند چگونه یک محیط کاری قابل اعتماد برای ایجنت از صفر بسازید:

۱. **فقط پرامپت در مقابل قوانین اول**: مقایسه کنید که یک ایجنت با تنها یک پرامپت در مقابل یک هارنس پایه چگونه عمل می‌کند.
۲. **فضای کاری قابل خواندن برای ایجنت**: یاد بگیرید چگونه ریپازیتوری خود را برای ایجنت دوستانه ساختار دهید و مکانیسم‌های تحویل ایجاد کنید.
۳. **تداوم چند جلسه‌ای**: فایل‌های وضعیت و اسکریپت‌های initialization طراحی کنید تا ایجنت شما می‌تواند کار را بدون مشکل در سراسر جلسات ادامه دهد.
۴. **بازخورد Runtime و کنترل دامنه‌ی کار**: ابزارهایی معرفی کنید که اجازه می‌دهند ایجنت کد خود را آزمایش کند و خطاها را در طول اجرا تصحیح کند.
۵. **خود-راستی‌آزمایی و جداسازی نقش**: یک مکانیسم بررسی مستقل بسازید تا از توهم‌ها و اعلام زودرس پیروزی جلوگیری کنید.
۶. **هارنس کامل (Capstone)**: یک محیط کاری ایجنت نهایی، قابل رصد و end-to-end جمع‌آوری کنید.
۷. **حلقه‌ی خودکار اول شما**: انتقال از راه‌اندازی دستی به حلقه خودکار — سه آزمایش پیش‌رفته: goal loop، timer loop، و maker-checker loop.

## چگونه ادامه دهید

هر پوشه‌ی پروژه عادة شامل موارد زیر است:
- `starter/`: فضای کاری شروع شما.
- `solution/`: یک پیاده‌سازی مرجع (اگر گیر‌کردید).
- دستورالعمل‌های کار که پس‌زمینه و اهداف خاص شما را تفصیل می‌دهند.

برای تکمیل کار‌ها در دایرکتوری `starter/`، از ایجنت هوش مصنوعی کدنویسی دلخواه خود (مثلاً Claude Code، Cursor، Trae) استفاده کنید.
