# معیار ارزیاب

از این معیار بعد از پیاده‌سازی و قبل از پذیرش نهایی استفاده کنید.

| دسته | سوال | امتیاز (0-2) | یادداشت |
| --- | --- | --- | --- |
| درستی | رفتار پیاده‌سازی‌شده با ویژگی درخواست‌شده مطابقت دارد؟ |  |  |
| راستی‌آزمایی | بررسی‌های الزامی واقعاً اجرا شد، با شواهد؟ |  |  |
| انضباط دامنه | آیا جلسه در دامنه‌ی ویژگی انتخاب‌شده باقی ماند؟ |  |  |
| اعتماد‌پذیری | آیا نتیجه بدون تعمیر، بازشروع یا تکرار را تحمل می‌کند؟ |  |  |
| نگهداری‌پذیری | آیا کد و مستند‌سازی برای جلسه‌ی بعدی واضح کافی است؟ |  |  |
| آمادگی تحویل | آیا جلسه‌ی جدید می‌تواند تنها از عامل‌های ریپازیتوری کار ادامه دهد؟ |  |  |

## رأی

- پذیرفتن
- اصلاح
- مسدود کردن
