# فهرست‌وار کار وضعیت پاک

- [ ] مسیر راه‌اندازی استاندارد هنوز کار می‌کند.
- [ ] مسیر راستی‌آزمایی استاندارد هنوز اجرا می‌شود.
- [ ] پیشرفت فعلی در گزارش پیشرفت ثبت‌شده است.
- [ ] وضعیت ویژگی منعکس می‌کند چه چیزی واقعاً تصدیق‌شده در مقابل تصدیق‌نشده است.
- [ ] هیچ مرحله‌ی نیمه‌تمام بدون مستند‌سازی باقی نمانده‌است.
- [ ] جلسه‌ی بعدی می‌تواند بدون تعمیر دستی ادامه دهد.
