# سند کیفیت

[نسخه‌ی انگلیسی ←](../../../en/resources/templates/quality-document.md)

یک عکس‌فوری کیفیت برای هر دامنه‌ی محصول و لایه‌ی معماری. ایجنت‌ها و انسان‌ها می‌توانند این سند را برای درک سریع آن‌جایی که پایگاه‌کد قوی است و کجا نیاز به کار دارد استفاده کنند.

**بسامد به‌روزرسانی:** بعد از هر جلسه‌ی قابل‌توجه، یا قبل از شروع یک فاز جدید کار.

**مقیاس درجه‌دهی:**

- **A**: تمام راستی‌آزمایی موفق، معماری پاک، خوانایی ایجنت، تست‌های پایدار
- **B**: راستی‌آزمایی موفق، بیشتر پاک، شکاف‌های جزئی در خوانایی یا پوشش تست
- **C**: جزئی‌اً کار می‌کند، شکاف‌های شناخته‌شده، برخی مناطق کد برای ایجنت‌ها درک کردن سخت
- **D**: کار نمی‌کند، یا مسائل ساختاری بزرگ
