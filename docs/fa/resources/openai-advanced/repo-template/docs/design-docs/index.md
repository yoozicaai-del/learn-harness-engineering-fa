## قوانین نگهداری

- هر سند طراحی باید مالک یا ماشین تغییر داشته باشد.
- اسناد کهنه را حذف کنید یا نسخه آن‌ها را منسوخ کنید تا نگذارید جابه‌جا شوند.
- طرح‌های فعال را به اسناد طراحی که به آن‌ها وابسته هستند پیوند دهید.
