# باورهای اصلی

- ریپازیتوری منبع حقیقت برای عوامل است.
- `AGENTS.md` یک مسیریاب است، نه دایره‌المعارف.
- شواهد راستی‌آزمایی بیش‌تر از اعتماد اهمیت دارد.
- یک کار محدود بهتر است از بسیاری کارهای نیمه‌تمام.
- بازخورد مکرر انسان باید به قوانین هارنس قابل استفاده مجدد تبدیل شود.
- پاکسازی و ساده‌سازی بخشی از واگذاری هستند، نه افکار نهایی.
- اگر یک عامل نتواند یک واقعیت را در ریپازیتوری کشف کند، آن واقعیت را به‌عنوان عملیاتی غیردسترس‌پذیر رفتار کنید.
