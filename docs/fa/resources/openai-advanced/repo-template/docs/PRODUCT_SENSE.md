# PRODUCT_SENSE.md

این فایل حکم محصول دوام‌دار را ثبت می‌کند که عوامل نمی‌توانند به‌طور قابل اعتماد از کد تنها استنتاج کنند.

## هسته‌ی محصول

- کاربر اصلی: `[جایگزین کنید]`
- کاری که باید انجام شود: `[جایگزین کنید]`
- نگرانی اصلی برای حذف: `[جایگزین کنید]`
- نوار کیفیت برای پذیرش: `[جایگزین کنید]`

## قوانین محصول

- اعتماد‌پذیری رو به کاربر را بر تعداد ویژگی ترجیح دهید.
- رفتار ابهام‌انگیز را به‌عنوان شکاف مشخصات رفتار کنید، نه به‌عنوان اجازه برای حدس.
- اگر اجرا آنچه را که کاربران می‌بینند یا به آن اعتماد دارند تغییر دهد، مشخصات مطابقت را به‌روز کنید.
- برای جریان‌های بتن از مشخصات محصول استفاده کنید، و برای اولویت‌های فراگیر محصول از این فایل استفاده کنید.

## الگوهای ممنوع

- عملیات‌های تخریبی پنهان
- شکست خاموش بدون بازخورد کاربر
- منبع حقیقت نامشخص برای وضعیت دیدنی
- ویژگی‌هایی که نمی‌توانند در یک جمله توضیح داده شوند
