# طراحی پایگاه داده

این پوشه را برای آثار تولیدی یا مشتق‌شده استفاده کنید که عوامل باید بتوانند بدون معکوس‌مهندسی‌کردن آن‌ها از کد بررسی کنند.

## منبع

- تولیدی از: `[دستور یا مسیر منبع]`
- آخرین تازه: `YYYY-MM-DD`

## یادداشت‌ها

- بخش‌های تولیدی را به‌دست ویرایش نکنید.
- این فایل را زمانی تولید مجدد کنید که طراحی زمینه‌ای تغییر کند.
