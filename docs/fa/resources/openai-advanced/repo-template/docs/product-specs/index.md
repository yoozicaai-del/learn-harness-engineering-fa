# نمایه‌ی مشخصات محصول

## مشخصات فعال

## قوانین

- مشخصات باید رفتار و معیارهای پذیرش رو به کاربر را توصیف کنند.
- اگر اجرا از مشخصات منحرف شود، یکی از آن‌ها را در همان جلسه به‌روز کنید.
- این نمایه را جاری نگه دارید تا یک عامل تازه بتواند محدوده‌ی محصول را سریع کشف کند.
