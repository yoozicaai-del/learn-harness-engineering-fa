# SOP‌های پیشرفته OpenAI

این SOP‌ها الگوهای عملیاتی مقاله را به پخش‌نامه‌های اجرای ملموس ترجمه می‌کنند که می‌توانید دنبال کنید یا اقتباس کنید.

## SOP‌های شامل

- [`layered-domain-architecture.md`](./layered-domain-architecture.md):
  لایه‌های صریح و مرزهای فراگیر را برقرار کنید
- [`encode-knowledge-into-repo.md`](./encode-knowledge-into-repo.md):
  دانش نادیده را از چت، اسناد و حافظه به فایل‌های محلی ریپازیتوری منتقل کنید
- [`observability-feedback-loop.md`](./observability-feedback-loop.md):
  عوامل را گزارش‌ها، معیارها، ردیابی‌ها و حلقه‌ی اشکال‌یابی قابل تکرار بدهید
- [`chrome-devtools-validation-loop.md`](./chrome-devtools-validation-loop.md):
  اتوماسیون مرورگر و لقطه‌ها را برای راستی‌آزمایی رفتار واجهه‌ی کاربری تا تمیز استفاده کنید

## نحوه استفاده

1. SOP را انتخاب کنید که با گلوگاه فعلی شما مطابقت داشته باشد.
2. از چک‌لیست برای تنظیم آثار یا ابزارهای گمشده استفاده کنید.
3. قوانین حاصل را در اسناد کپی‌شده‌ی `repo-template/` رمزگذاری کنید.
4. نظرات بررسی تکراری را به بررسی‌ها، اسکریپت‌ها یا حفاظ‌ها تبدیل کنید.

این قصد نیست که به‌صورت کور دنبال شوند. آن‌ها قصد دارند هارنس را قابل‌فهم‌تر، اعمال‌پذیرتر و قابل تکرار کنند.
