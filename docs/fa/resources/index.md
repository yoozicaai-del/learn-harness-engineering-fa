# کتابخانه‌ی منابع

این پوشه روش‌های دوره را به الگوهای آماده‌ی کپی و منابع فشرده تبدیل می‌کند که می‌توانید در یک ریپازیتوری واقعی استفاده کنید.

## کی از آن استفاده کنید

اینجا شروع کنید وقتی می‌خواهید Codex، Claude Code یا یک ایجنت کدگذاری دیگر روی چندین جلسه کار کند بدون اینکه مدام راه‌اندازی، وضعیت و دامنه‌ی کار را دوباره بسازد.

مخصوصاً وقتی مفید است:

- کار چندین جلسه را پوشش می‌دهد
- قابلیت‌ها زیادند و به‌آسانی نیمه‌تمام می‌مانند
- ایجنت‌ها تمایل به اعلام پیروزی خیلی زود دارند
- مراحل شروع هر دفعه دوباره کشف می‌شوند

## از اینجا شروع کنید

برای راه‌اندازی کمینه، ابتدا با شروع کنید:

- دستورالعمل‌های ریشه: [`templates/AGENTS.md`](./templates/AGENTS.md) یا [`templates/CLAUDE.md`](./templates/CLAUDE.md)
- وضعیت قابلیت: [`templates/feature_list.json`](./templates/feature_list.json)
- گزارش پیشرفت: [`templates/claude-progress.md`](./templates/claude-progress.md)

نام فایل یک کنوانسیون دوره‌ی تاریخی است. این یک گزارش پیشرفت جلسه‌ی محلی برای ریپازیتوری عام است: هر ایجنت کدگذاری می‌تواند از آن استفاده کند، اما ایجنت‌ها تنها زمانی آن را می‌خوانند یا به‌روزرسانی می‌کنند که دستورالعمل‌های آن‌ها صریحاً آن‌ها را بگویند.
- مرجع اسکریپت bootstrap: `docs/en/resources/templates/init.sh`

سپس اضافه کنید:

- تحویل جلسه: [`templates/session-handoff.md`](./templates/session-handoff.md)
- فهرست‌ی خروج پاک: [`templates/clean-state-checklist.md`](./templates/clean-state-checklist.md)
- rubric ارزیاب: [`templates/evaluator-rubric.md`](./templates/evaluator-rubric.md)

اگر ساختار ریپازیتوری سبک OpenAI از پست "مهندسی هارنس" را می‌خواهید، از بسته پیشرفته استفاده کنید:

- [`openai-advanced/index.md`](./openai-advanced/index.md)

## ساختار کتابخانه

- [`templates/`](./templates/index.md): الگوهای کپی‌کن در ریپازیتوری واقعی
- [`reference/`](./reference/index.md): یادداشت‌های روش، جریان شروع و نقشه‌های حالت‌ناموفق
- [`openai-advanced/`](./openai-advanced/index.md): اسکلت ریپازیتوری پیشرفته، اسناد سیستم‌ریکاری و الگوهای حاکمیت ایجنت‌اول

## بسته‌ی کمینه توصیه‌شده

- `AGENTS.md` یا `CLAUDE.md`
- `feature_list.json`
- `claude-progress.md` (گزارش پیشرفت جلسه‌ی عام؛ نام فایل تاریخی)
- `init.sh`

این چهار فایل کافی است تا بیشتر جریان‌های کار ایجنت به‌طور نمایانی پایدارتر شوند.

زمانی‌که ریپازیتوری به سیستمی طولانی‌مدت با چندین دامنه، نقشه‌های فعال، امتیازدهی کیفیت و سیاست‌های قابلیت اعتماد رشد کند، به‌جای کشش بسته‌ی کمینه خیلی دور، به‌جای آن به بسته‌ی [`openai-advanced/`](./openai-advanced/index.md) بروید.
