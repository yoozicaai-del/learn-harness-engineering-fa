# فهرست بررسی سیستم رکورد

آیا یک ایجنت تازه می‌تواند موارد زیر را از ریپازیتوری به تنهایی کشف کند؟

- چه محصولی ساخته می‌شود؟
- برنامه باید برای کاربران چه کاری انجام دهد؟
- کد‌بیس چگونه سازماندهی شده‌است؟
- برنامه چگونه شروع می‌شود؟
- سلامت سیستم چگونه بررسی می‌شود؟
- کدام کارها در حال حاضر در جریان هستند؟
- کدام استانداردهای کیفیت اهمیت دارند؟
