## روش راستی‌آزمایی

<!-- نحوه‌ی راستی‌آزمایی بعد از هر مرحله -->

1. بعد از اجرا، این دستورات را به‌ترتیب اجرا کنید:
   1. `npx tsc --noEmit` — type check
   2. `npm run lint` — سبک کد
   3. `npm test` — آزمون‌های واحد
   4. `npx vitest --coverage` — بررسی coverage

2. هرگونه شکست را قبل از رفتن به مرحلهٔ بعدی برطرف کنید.
3. وقتی همه چیز می‌گذراند، مجموعهٔ کامل آزمون انتهایی را اجرا کنید (اگر موجود باشد).

## شرایط توقف

- تمام معیارهای پذیرش می‌گذرند ✅
- حداکثر turn رسید: 20
- بدون پیشرفت برای 3 raund متوالی (خطای یکسان همچنان ظاهر می‌شود)
- مشکل بلاکه‌کننده که نمی‌تواند به‌طور مستقل حل شود (مثل وابستگیٔ گم‌شده، مشکل محیط)

## نحوه‌ی کار

1. ابتدا `AGENTS.md` و `feature_list.json` را بخوانید تا ساختار پروژه و ویژگی‌های موجود را درک کنید.
2. طراحی رویکرد خود را قبل از لمس کدن بنویسید.
3. بعد از اتمام هر زیر‌کار راستی‌آزمایی کنید.
4. اگر برای بیش از 2 raund گیر افتادید، رویکرد را تغییر دهید یا ساده‌تر کنید.
5. پیشرفت را در انتهای هر raund به‌روز کنید.
