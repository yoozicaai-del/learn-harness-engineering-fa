# کد سخنرانی ۱۴

از این پوشه برای ذخیره‌ی نمونه‌ها برای موارد زیر استفاده کنید:

- graph.md قالب توصیف گراف (گره‌ها / یال‌ها / وضعیت مشترک / قوانین مسیریابی)
- node-prompt.md قالب پرامپت نقش گره
- routing-rules.md قالب قوانین مسیریابی
- maker_checker_graph.py پیاده‌سازی مرجع (وابسته‌ی فریم‌ورک: LangGraph): شش مرحله‌ی «ساختن اولین گراف خود را از ابتدا» را به کد قابل‌اجرا تبدیل می‌کند — شمای وضعیت، گره‌ها، یال‌ها، مسیریابی شرطی، چک‌پوینت. بدنه‌ی سخنرانی بی‌وابستگی به فریم‌ورک است؛ این یک روش عملی برای نوشتن آن است
- نمونه‌های اسکریپت کنترل گراف (اجرای گراف، بررسی چک‌پوینت‌ها، تریگر تأیید انسان)
