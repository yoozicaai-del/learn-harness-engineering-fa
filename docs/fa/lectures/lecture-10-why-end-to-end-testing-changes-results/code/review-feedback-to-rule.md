# مثال: تبدیل بازخورد بررسی به قاعده

نظر بررسی تکرارشونده:

> از utilities سیستم‌فایل در renderer فراخوانی نکن. از پل preload استفاده کن.

قاعده‌ی هارنس ارتقاء‌یافته:

- یک قاعده‌ی lint یا import اضافه کن که استفاده‌ی `fs` را در کد renderer جلوگیری کند
- متن اصلاح را شامل کن که مرز preload را توضیح دهد
