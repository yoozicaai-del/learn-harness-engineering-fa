# نمونه‌ی وظیفه‌ی نامشخص

ساخت یک اپ پایگاه اطلاعات دسکتاپ با پاسخ‌دهی سؤال توسط هوش مصنوعی.

محدودیت‌ها:

- هیچ‌کدام مشخص نشده
- هیچ دستور شروع داده نشده
- هیچ راهنمایی ساختار پوشه
- هیچ مدل داده‌ای تعریف‌نشده
- هیچ معیار تکمیل صریح

نتایج معمول از این‌گونه پرامپت‌ها:

- ایجنت ساختار را بدون‌پیش‌‌برنامه ایجاد می‌کند
- اپ ممکن است کامپایل شود اما شروع‌نشدنی نباشد
- رابط کاربری ممکن است قبل از وجود هر مسیر مصرف/پرس‌و‌جو ظاهر شود
- ایجنت اغلب پس از موفقیت آرایشی متوقف می‌شود
