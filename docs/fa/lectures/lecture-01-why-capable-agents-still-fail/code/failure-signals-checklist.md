# فهرست‌ی نشانه‌های شکست

این فهرست را هنگام بررسی اجرای ضعیف هارنس استفاده کنید.

- آیا ایجنت از نحوه‌ی شروع اپ سؤال پرسید یا به‌طور نادرست استنتاج کرد؟
- آیا فهرست‌های فهرستی یا انتزاع‌هایی ایجاد کرد که با محصول مورد نظر مطابقت ندارند؟
- آیا پس از ایجاد پوسته رابط کاربری مرئی بدون یک جریان کاری کامل متوقف شد؟
- آیا یادداشت‌ها یا اشیاء باقی گذاشت که کمک می‌کنند نوبت آینده ادامه دهد؟
- آیا یک جلسه‌ی جدید می‌تواند درعرض پنج دقیقه درک کند چه اتفاقی افتاد؟
