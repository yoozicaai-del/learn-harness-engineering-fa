# مثال تحویل جلسه

## تکمیل شده

- پشتیبانی وارد‌کردن markdown اضافه کردم
- یک فهرست سند اساسی در رندرر اضافه کردم

## شکسته یا راستی‌آزمایی نشده

- وارد‌کردن برای `.md` موفق است اما برای فایل‌های بزرگ `.txt` ناموفق است
- برنامه شروع می‌شود، اما نمای جزئیات متصل نشده است

## بهترین گام بعدی

- مسیر وارد‌کردن `.txt` را رفع کن
- وارد‌کردن را انتها به انتها راستی‌آزمایی کن
- سپس پانل جزئیات سند را اضافه کن
